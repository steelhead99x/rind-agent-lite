# Security

## Reporting a vulnerability

Please report security problems privately through GitHub's
[Report a vulnerability](https://github.com/steelhead99x/rind-agent-lite/security/advisories/new)
form on this repository's Security tab. Do not open a public issue for them.

Include what you found, how to reproduce it and the impact you expect.
There is no bounty and no promised response time.

This repository holds agent skills, not cryptography. Report problems in rind itself to [kixel-ai/rind](https://github.com/kixel-ai/rind/security).

Bugs that are not security problems can go in a normal issue.
